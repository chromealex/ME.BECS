# BECS Remote Debug

Add `BECS_REMOTE_DEBUG` to Unity Player Settings → Scripting Define Symbols for the target platform. Without it the addon assembly is excluded. WebGL is excluded because it cannot host an HTTP listener.

In Play Mode or a player build, the server starts automatically on TCP port 8787. Click Copy URL in the application and paste the complete link into a browser on another device in the same network. The link includes the per-launch token in its fragment and connects automatically. Active LAN IPv4 addresses are displayed; Refresh IP updates them after a network change. You can also enter the token manually. Allow incoming TCP 8787 through the device firewall. The application must continue updating (enable Run In Background if needed).

Dashboard shows registered worlds, ticks, entity counts and allocator totals. Hierarchy shows the selected world's live entities and transform parents (up to 10,000), with expandable branches and a case-insensitive name/ID search (including #ID). Branches start collapsed; the arrow toggles children independently of entity selection. Expansion is remembered per world and entity generation during the browser session. Search temporarily reveals ancestor paths to matches; clearing it restores the existing expansion state. Selecting an entity opens a read-only inspector for ordinary, shared and static components, their enabled/tag state, and serialized field values. Selected entities are identified by world, ID and generation, so an ID reused after destruction does not silently select a new entity. Inspector data refreshes once per second. Replays shows current/target ticks, stored state ticks and up to 2,000 network events, with Live and Rewind controls. Tick values are absolute and transmitted as strings to preserve 64-bit precision.

ECS reads and replay commands run in late Unity updates after completing world jobs. HTTP threads only queue requests. At most 16 requests are queued, with four processed per frame. Polling is once per second. Remote inspection can stall the main thread in large worlds; enable this define only for diagnostic builds.

This is a runtime web view, not a copy of Editor windows. Component editing, replay file import/export, allocator graphs and Editor selection are not implemented. Rewind uses the NetworkModule stored range and synchronizes views; Live restores network time. The game keeps running in player builds.

Use only on a trusted LAN: HTTP is unencrypted. Token authentication covers data and command endpoints. HttpListener availability and firewall permissions must be checked on each target platform, especially IL2CPP/mobile.

Inspector limits: up to 256 components, 512 fields per component, six nested levels, and collections up to 128 elements. Larger unmanaged collections show their count and an omission notice. Pointer addresses and arbitrary reference objects are not exposed. Component reads use BECS managed reflection readers; stripped IL2CPP builds may need preserved component metadata/generic readers. Read failures are shown per component and must be verified on the target player.

The Pause / Play toggle in the header controls the selected world's BaseWorldInitializer. Pause completes the current world jobs and disables automatic initializer callbacks; the remote server and other worlds continue running. Play only resumes an initializer paused by this debug server. The toggle is hidden for All worlds and unavailable for worlds without a matching initializer. Closing a world tab does not resume it; removing the debug server restores initializers it paused. Pausing a network world does not pause the remote transport/server clock; resuming may trigger network catch-up. Play and replay Live are separate controls.

Hierarchy keyboard controls (while a hierarchy row has focus): Up/Down select adjacent visible entities; Right expands a branch or moves to its first visible child; Left collapses a branch or selects its parent; Home/End select the first/last visible entity. Selection updates the inspector. Focus is preserved across snapshot refreshes. Search input arrows keep their usual text-editing behavior.

The inspector starts with a case-insensitive search across component names, field names and values. Component captions omit namespaces and the Component suffix; vector axes share one row. Entity references show their generation and current version (or — when no longer alive). Select opens the referenced entity in its world tab, expands its ancestor path and displays its components. Reference selection validates the generation before navigating. Entity generation and version also appear in hierarchy rows. All worlds contains only the dashboard; the + menu opens individual world tabs.

Hierarchy and components have independent scroll areas with fixed search controls and preserved scroll positions during refresh. On narrow screens they stack vertically. Replays displays States, Local and Remote tick lanes, a selected-tick cursor and a slider. Slider release sends Rewind; the Tick field can select an exact 64-bit tick. Local events are identified by the network module local player ID.
